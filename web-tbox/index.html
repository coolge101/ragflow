TBOX 控制台

不要用资源管理器双击、或用浏览器直接打开本文件的 file:// 地址。入口里脚本为 /src/main.tsx，在本地文件协议下无法正确加载，会一直空白或报错。

正确做法：

  1. 在终端进入目录 web-tbox；
  2. 执行 npm install（首次），再执行 npm run dev；
  3. 在浏览器打开终端里给出的地址，一般为 http://127.0.0.1:5174。

若只想看静态 HTML 线框，可打开同仓库下的 web-tbox/public/ui-pages/index.html（用 file:// 打开该路径即可）。

若你已启动开发服务，下方脚本成功后会由 React 替换本段说明。
